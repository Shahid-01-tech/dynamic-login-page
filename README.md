# Mini Web Project

A simple front-end web project built using **HTML, CSS, and JavaScript**.  
This project demonstrates basic web development concepts including page structure, styling, and interactive functionality.

## 🚀 Features
- Clean and simple user interface
- Responsive layout
- Basic JavaScript interactivity
- Beginner-friendly project structure

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
project-folder

│

├── index.html

├── style.css

└── script.js

## 📌 Purpose
This project was created as a practice project to improve my front-end development skills and understand how HTML, CSS, and JavaScript work together to build a web application.

## ▶️ How to Run
1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in your browser
